# 字体目录（可选）

程序**不内置任何字体文件**，默认使用系统自带的 `Microsoft YaHei`。

如果你想换字体，有两种方式：

1. **在程序里加载（推荐）**：右键圆环 → 设置 → 字体 → 浏览字体文件…，
   选择一个 `.ttf` / `.otf` / `.ttc` 文件即可，路径会记入 QSettings，下次启动自动恢复。
2. **放进这个目录**：把字体文件放到 `assets/fonts/` 下，程序启动时会自动扫描并
   把字体名加入“字体”菜单。

## 为什么这里原本的 simsun.ttc 被删掉了

- 代码里查找的文件名是 `上首软糖体.ttf`，与仓库里的 `simsun.ttc` 不一致，
  所以它**从未被真正加载过**，只是一直占着 18 MB 的仓库体积和打包体积；
- `simsun.ttc`（宋体）是微软 / 中易的商业字体，**不适合随开源仓库分发**。

自行添加字体时请确认该字体允许再分发。
